# بوت تلقرام — استقبال طلبات المخططات وإرسالها

صاحب المصنع يرسل الطلب على تلقرام (نص، صور، كروكي، فويس، فيديو، PDF).
البوت يمرّره لـ Claude Code داخل المستودع، وClaude يشتغل بنفس طريقة المصنع (CLAUDE.md)،
وبعدها البوت يرجّع الرد والملفات (PDF / DXF / صور) لنفس المحادثة.

## التجهيز (مرة وحدة)
1. في تلقرام افتح **@BotFather** ← `/newbot` ← اختر اسم البوت ← ينطيك **توكن**.
   التوكن سري: لا ترسله لأحد ولا تكتبه بأي ملف بالمستودع.
2. على جهاز يكون شغّال دايماً (كمبيوتر المصنع أو سيرفر):
   - انسخ المستودع وثبّت المتطلبات: `pip install -r requirements.txt`
   - ثبّت Claude Code وسجّل دخول: `npm i -g @anthropic-ai/claude-code` ثم `claude`
3. شغّل البوت:
   ```bash
   export TELEGRAM_BOT_TOKEN='التوكن'
   python tools/telegram_bot.py
   ```
   أرسل أي رسالة للبوت، يرد عليك **برقم محادثتك**.
4. وقّف البوت وشغّله مرة ثانية بالرقم:
   ```bash
   export TELEGRAM_ALLOWED_IDS='رقم_المحادثة'
   python tools/telegram_bot.py
   ```
   البوت ينفّذ طلبات الأرقام المسموحة بس. أي أحد ثاني ما ينفّذ له شي.

## الاستخدام
- أرسل الطلب عادي، مثلاً: «مجلس 6×5 صالة وحمام ومطبخ أمريكي» مع الصور.
  الصور المتعددة (ألبوم) تنحسب طلب واحد.
- البوت يرد «وصل الطلب ✅» وبعدها يرسل الأوتوكاد والملخص.
- البوت يتذكر المحادثة، فتقدر تكمل بالتعديلات («ارفع السقف»، «الواجهة زجاج»…).
- `/new` يبدأ مشروع/جلسة جديدة.

## ملاحظات
- المرفقات تنحفظ خارج المستودع في `~/.watad-telegram/inbox`، حفاظاً على خصوصية العملاء.
- الجهاز لازم يكون شغّال ومتصل بالنت، لأن البوت يشتغل عليه (long polling، ما يحتاج دومين).
- عشان يشتغل البوت تلقائياً بعد إعادة التشغيل: خدمة systemd أو `tmux`/`screen`.
