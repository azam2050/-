# وتد — مصمم أكواخ مصنع وتد الأخشاب

نظام يستقبل طلب تصميم من المصنع، يطبّق **قواعد المصنع الحقيقية** (`docs/factory-spec.md`)
ويُخرج: ملف أوتوكاد DXF + ملف PDF للعميل والورشة + نموذج 3D + جدول كميات وخطة تقطيع الطبليات.

## الوضع الحالي (المرحلة 1 — المحرك)

```bash
pip install -r requirements.txt
python -m watad examples/sample_cabin.yaml -o out/
```

المخرجات في `out/`:

| الملف | المحتوى |
|---|---|
| `*.dxf` | يفتح في أوتوكاد: المسقط + واجهة تأطير لكل جدار، طبقات منفصلة (قواعد، أعمدة، إطارات، فتحات، أبعاد) |
| `*.pdf` | مسقط، واجهات تأطير بالعربي، جدول كميات، نقاط تحتاج تأكيد |
| `*_3d.obj` + `.mtl` | نموذج 3D كامل بالمواد والألوان — يُستورد في 3ds Max (الوحدة سم، Z للأعلى) |
| `*_3d.glb` | نفس النموذج بصيغة glTF (متر) — 3ds Max 2023+ / Blender / عارض ويب |
| `*_3d.png` | معاينة منظور من جهتين |
| `*_frame.obj` | هيكل التأطير 3D (للورشة) |
| `*_bom.json` | الكميات بصيغة آلية (للبوت والتسعير لاحقاً) |

القواعد المطبقة: قاعدة سفلية تمر تحت الأبواب (مع ملاحظة القطع لاحقاً)، أعمدة كل 60،
إطار 7×5 للفتحات، أعمدة قصيرة تحت الجلسة، علوي واحد، عمودين لكل زاوية، ترفيع الارتفاع
لآخر لوح كامل، مدادات جملون كل 60، خطة الطبليات (الطريقة الأولى لكل مداد + الطريقة الثانية
3 أعمدة للباقي)، التلبيس من الجهتين، أسمنت بورد لداخل دورات المياه، العزل عند الطلب.

الألوان والمواد: `style: honey_burgundy` في ملف المشروع (الأنماط في `config/style_presets.yaml`،
الشرح في `docs/style-guide.md`). الدكة والدربزين: `decks:` (انظر `examples/sample_cabin.yaml`).

## الهيكل

```
config/factory_rules.yaml   ← كل أرقام المصنع (تعديلها لا يحتاج برمجة)
docs/factory-spec.md        ← المرجع الأصلي من المصنع
watad/framing.py            ← تأطير الجدار
watad/roof.py               ← الجملون والمدادات
watad/quantities.py         ← الطبليات، التلبيس، الأسمنت بورد، العزل
watad/height.py             ← قاعدة الارتفاع
watad/dxf_out.py | pdf_out.py | obj_out.py
examples/                   ← ملفات مشاريع
```

## الخطة القادمة

1. **معايرة على مشروع حقيقي:** ملف عميل أمس (DWG/DXF/PDF) → نقارن مخرجات المحرك بالرسمة البشرية ونصحح القواعد.
2. **قراءة ملف أوتوكاد العميل:** استخراج الجدران والفتحات تلقائياً من DXF (طبقات) بدل كتابتها يدوياً.
3. **استقبال الطلبات:** بوت تلقرام لمدير المصنع (نص/صورة كروكي/ملف) + بريد إلكتروني احتياطي →
   Claude يحوّل الطلب لملف مشروع → المحرك يرسم → يرجع PDF + DXF في نفس المحادثة، مع أسئلة لو ناقص شي.
4. **3D للعرض:** نموذج كامل (تلبيس + سقف) بصيغة FBX/glTF لـ 3ds Max، ورندر صور للعميل.
5. **تسعير** من جدول الكميات.
